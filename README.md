# E-Commerce Sales & Profitability Analysis

An end-to-end E-Commerce Sales & Profitability Analysis project using **Python, MySQL and Power BI**.

## 📌 Project Overview

This project analyzes historical e-commerce sales data to understand sales trends, product performance, regional demand, and profitability.

The project follows a complete data analytics workflow:

**Python → MySQL → Power BI → Business Insights**

## 🎯 Business Problem

The business needs to understand:

- How sales and profit change over time
- Which categories and products perform well
- Which regions generate higher sales and profit
- Which products contribute to profitability
- Whether high-sales products are also profitable

## 🎯 Project Objectives

- Clean and validate the sales dataset
- Perform exploratory data analysis using Python
- Analyze business metrics using SQL
- Build an interactive Power BI dashboard
- Identify important business insights
- Provide data-driven business recommendations

## 📊 Dataset

The dataset contains **3,500 sales transactions** with the following columns:

- Order Date
- Product Name
- Category
- Region
- Quantity
- Sales
- Profit
